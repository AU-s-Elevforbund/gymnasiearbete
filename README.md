# Gymnasiearbete: programmeringsexempel

Exempel i Python för dig som gör ett gymnasiearbete inom astronomi och rymd. Varje exempel är ett litet projekt med frågeställning, data, analys och slutsats, och går att köra direkt i webbläsaren med Google Colab utan att installera något.

Materialet tas fram av Astronomisk Ungdoms Elevförbund och hör till [rymdelev.se](https://rymdelev.se). Exemplen förutsätter att du kan grunderna i Python.

## Så använder du exemplen

Klicka på **Open in Colab** för att öppna ett exempel. Du kan köra all kod direkt. Vill du spara dina ändringar väljer du *Arkiv > Spara en kopia på Drive*.
